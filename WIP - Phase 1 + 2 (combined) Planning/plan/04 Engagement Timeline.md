## Critical Path

```
Phase 0 gaps closed
  → Week 1: Kickoff + Phase 0 validation
    → Week 2: "System of One" decision
      → Week 3-4: Strategy decisions (franchise, data, AI, KPIs)
        → Week 4: Strategy Playbook draft (Deliverable 1)
      → Week 3-5: Architecture design
        → Week 4-6: Vendor evaluation
          → Week 6-7: Implementation wave plan
            → Week 7-8: Blueprint compilation (Deliverable 2)
              → Week 8: Sign-off
```

**Critical dependencies:**
1. "System of One" decision (Week 2) gates all architecture work
2. Architectural guardrails (Week 1-2) constrain vendor shortlisting
3. Vendor direction (Week 6) informs implementation wave plan
4. Strategy Playbook sign-off should precede Architecture Blueprint review
